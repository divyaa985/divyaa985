# Divya Mandalaywala

Bioinformatician. I work on evaluation: whether a complicated model actually beats a simple one, and whether either beats a control with no signal in it.

### Projects

**[scfm-benchmark](https://github.com/divyaa985/scfm-benchmark)** — Do single-cell foundation model embeddings beat a PCA baseline on a sequencing technology the model has never seen? Leak-free preprocessing, a random-projection control, fold-level results published alongside the summaries.

**[pancancer-survival-bench](https://github.com/divyaa985/pancancer-survival-bench)** — Does gene expression improve cancer prognosis over age, sex and stage? And does it beat a signature of randomly drawn genes? Censoring-aware metrics and stratified cross-validation across TCGA cancer types.
